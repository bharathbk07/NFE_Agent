# Record flow then publish

> Record (Watch-me) or reuse a recording, build/run script path, publish Confluence evidence.

## When to use
- User asks to record a journey / Watch-me
- “Capture create-claim then publish to Confluence”

## Guidance
1. `list_recordings` — reuse if a good recording exists.
2. Else `request_watch_me` with URL (confirm if needed).
3. After a script/smoke exists, `format_run_report`.
4. `sync_confluence_trends` or advise Confluence publish when authorized.

## Constraints
- Headed browser cannot run inside pure tool sandbox — handoff phrase is OK.
