# HEARTBEAT

> Periodic autonomy checklist for the PE Agent OS (when NFE_HEARTBEAT_ENABLED=true).

## Checklist
1. Are there eligible `nfe-agent` To Do / In Progress stories? (`list_jira_stories`)
2. Any unfinished API jobs / obvious failed smoke needing attention?
3. If nothing actionable → respond exactly: HEARTBEAT_OK
4. If actionable → briefly propose next PE action; only execute if policy allows without a user (prefer propose).
